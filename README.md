# Manasvi Sharma — Portfolio

A React + Vite personal portfolio for Manasvi Sharma, Computer Science & Engineering student at Lovely Professional University.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

The profile photo is included at `public/manasvi-photo.jpg`.
